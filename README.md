# ByteBuddy_App
An AI tutor specifically tailored to assist Doral Academy STEM students, particularly in Mr. Del Valle's classes. It uses the socratic method in which it asks a student questions to keep them engaged and doesn't automatically give the answers but provides hints and pushes.
